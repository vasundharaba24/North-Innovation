# NOVALIE - Premium E-commerce Collection

This is a React project that implements a premium e-commerce landing page for NOVALIE, showcasing a curated collection of home decor, candles, vases, and luxury accessories.

## Project Structure

```
novalie-react-app
├── public
│   ├── favicon.ico          # Favicon for the application
│   ├── manifest.json        # Metadata about the application
│   └── index.html           # Main HTML file serving as the entry point
├── src
│   ├── assets               # Folder for static assets (images, fonts, etc.)
│   ├── components           # Contains reusable components
│   │   ├── Carousel.tsx     # Carousel component for showcasing products
│   │   ├── Footer.tsx       # Footer component
│   │   ├── Header.tsx       # Header component with navigation
│   │   └── HeroSection.tsx  # Hero section component for main promotional area
│   ├── pages
│   │   └── LandingPage.tsx  # Main landing page component
│   ├── App.tsx              # Main application component
│   ├── index.tsx            # Entry point for the React application
│   ├── styles               # Folder for styles
│   │   ├── main.css         # Custom styles
│   │   └── tailwind.css     # Tailwind CSS styles
│   └── types                # Folder for TypeScript types
│       └── index.ts         # Type definitions
├── package.json             # npm configuration file
├── tailwind.config.js       # Tailwind CSS configuration
├── tsconfig.json            # TypeScript configuration
└── README.md                # Project documentation
```

## Getting Started

To get started with the project, follow these steps:

1. **Clone the repository:**
   ```
   git clone <repository-url>
   cd novalie-react-app
   ```

2. **Install dependencies:**
   ```
   npm install
   ```

3. **Run the application:**
   ```
   npm start
   ```

4. **Open your browser:**
   Navigate to `http://localhost:3000` to view the application.
